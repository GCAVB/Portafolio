Sobre mí

Soy desarrollador web Full Stack formado en JavaScript, con foco en crear soluciones claras y mantenibles para pequeños negocios. Mi principal proyecto es Atlántida360, una plataforma en desarrollo para un negocio de impresiones y fotocopias. En este proyecto he trabajado en la experiencia de cotización, procesamiento de documentos PDF, formularios, integración con una API y despliegue web. Busco colaborar con clientes que necesiten mejorar su presencia digital o simplificar procesos mediante herramientas web. También estoy abierto a oportunidades Full Stack Junior donde pueda seguir aprendiendo y aportar experiencia práctica construyendo productos completos.

Me interesa transformar requisitos reales en productos web claros, accesibles y mantenibles: interfaces responsive, APIs REST, autenticación, bases de datos y despliegue en producción.

Proyecto para negocio real · Sitio público activo

Atlántida360

Plataforma web para un negocio de impresiones, fotocopias y digitalización en Estación Central. Permite consultar servicios, cotizar documentos según páginas y opciones de impresión, cargar varios PDF y enviar solicitudes mediante un formulario.

Proyecto Full Stack con API REST desarrollada con Node.js y Express, autenticación JWT, PostgreSQL, Google Cloud Storage mediante Signed URLs y arquitectura profesional basada en capas.

  • Cotización por páginas, copias, impresión y anillado.
  • Carga múltiple de PDF con drag & drop.
  • Lectura de páginas y detección de archivos ilegibles.
  • Diseño responsive, tema claro/oscuro y rutas limpias.
  • API y almacenamiento privado en proceso de migración.
