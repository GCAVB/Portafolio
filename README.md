# Portafolio Full Stack

Portafolio profesional enfocado en el desarrollo de **sitios web y soluciones Full Stack para pequeños negocios**, además de presentar proyectos realizados durante mi formación en desarrollo JavaScript.

El objetivo de este portafolio es mostrar proyectos reales y académicos, las decisiones técnicas tomadas durante su desarrollo y mi evolución como desarrollador.

Actualmente, mi proyecto principal es **Atlántida360**, una plataforma web en desarrollo para un negocio real de impresiones, fotocopias y digitalización.

# Proyecto destacado

## Atlántida360

**Proyecto para negocio real · En desarrollo**

Atlántida360 es una plataforma web desarrollada para un negocio de **impresiones, fotocopias, digitalización y servicios relacionados con documentos** ubicado en Estación Central, Santiago de Chile.

El proyecto busca digitalizar parte del proceso de atención al cliente, permitiendo consultar servicios, realizar cotizaciones y preparar documentos antes de acudir al negocio.
